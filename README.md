# Python Communities

An open, community-maintained directory of Python communities around the
world: meetups, conferences, and organizations, shown on a map and
searchable by category and country.

## Development

```
pnpm i
pnpm dev
```

## Contributing

Anyone can add or update a community listing by opening a pull request.
See [CONTRIBUTING.md](CONTRIBUTING.md) for how.

## Theme

This theme is based on the [microstore](https://github.com/michael-andreuzza/microstore).
