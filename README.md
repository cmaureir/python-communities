# Python Communities

An open, community-maintained directory of Python communities around the
world: meetups, conferences, and organizations, shown on a map and
searchable by category and country.

The initial set of communities was sourced from the
[PSF Meetup Pro Network](https://www.meetup.com/pro/python-software-foundation-meetups/)
and the PyData Meetup network, cross-referenced against community directories
like [techtribes](https://github.com/olegp/techtribes) to fill in gaps. See the
site's Legal Notice page ([source](src/pages/legal.astro)) for how this content
is licensed and attributed.

## Development

```
pnpm i
pnpm dev
```
