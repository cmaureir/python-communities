The Python language is a rarity in the software industry: accessible to almost everyone, versatile across application domains, and generally a joy with which to work. While enjoying Python alone is beneficial, [PyRVA](https://pyrva.org) believes that Python is best enjoyed in the company of others. We're busy organizing talks, hackathons, workshops and more to help build up the Python community here in Richmond.

Follow us on [Twitter](http://twitter.com/PyRVA) and [GitHub](http://github.com/PyRVA).

PyRVA follows the [PSF Code of Conduct](https://www.python.org/psf/codeofconduct/).
