Welcome to the Official Python Nigeria Meetup! The aim of Python Nigeria is to advance the use and popularity of python as a programming language in Nigeria. Our group is dedicated to connecting Python enthusiasts in Nigeria who are passionate about open source, application architecture, Python in the Cloud, software development, data science, Python web development, and various open source Python interests. Join us to network, share knowledge and insights, and collaborate on exciting projects within the Python community. Let's embrace the power of Python together! All skill levels are welcome.

Every event wether in-person or virtual is bound by the [Python Software foundation Code of Conduct](https://www.pynigeria.org/about/coc/). If you've experienced any CoC violation please reach out to [coc@pynigeria.org](coc@pynigeria.org)
