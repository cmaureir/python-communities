DesertPy is the Phoenix area Python Meetup Group that promotes, educates and advances a diverse Python community through outreach, education, conferences, events and social gatherings. Ask Python questions of any level, beginner through advanced. Make connections with other local Pythonista. Get help with your conference talk proposals. Find others to hack with.

Any Developers, Aspiring Developers, Nerds and Hackers with an interest in Python are encouraged to participate!

We abide by the Python Software Foundation's [code of conduct](https://www.python.org/psf/conduct/).

Please join us \~
