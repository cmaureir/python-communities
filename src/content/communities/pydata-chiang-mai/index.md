PyData Chiang Mai is a community of data enthusiasts, researchers, and developers who use Python and open-source tools for data science, machine learning, and AI. We host meetups, talks, and workshops to share knowledge, exchange ideas, and build connections within the local data community.

PyData is an educational program of NumFOCUS, a 501(c)3 non-profit organization in the United States. The PyData Code of Conduct governs this meetup. To discuss any issues or concerns relating to the code of conduct or the behavior of anyone at a PyData meetup, please contact NumFOCUS at admin@pydata.org or the group organizer.
