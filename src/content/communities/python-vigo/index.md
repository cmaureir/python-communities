Python Vigo organizes regular meetups in Vigo, Spain, typically hosted at the Asociación Tecnológica A Industriosa. Sessions cover recent Python releases, practical workshops (like building AI agents with Python), and other community talks, usually followed by PyBirras — an informal after-meetup gathering.

Community channels include a mailing list (the only 100% official channel), Bluesky, and a Telegram group.
