RocPy is Rochester's local (and only!) Python user group. We exist to give others the opportunity to work and play with local Python developers, learners, employers, and enthusiasts. All skill levels are welcome.

* Monthly presentation series: 45-60 minute presentations on topics of interest to the Python community.
* We welcome 5-10 minute lightning talks.
* If there is interest in workshops, we would love to help coordinate them.
* See a selection of previous meetings on [YouTube](https://www.youtube.com/@rocpy4).

In the spirit of community, we adhere to the [Python Software Foundation Code of Conduct](https://policies.python.org/python.org/code-of-conduct/) and further express our values in our own [code of conduct](https://rocpy.org/code_of_conduct/).
