Cambridge Python User Group (CamPUG) is a monthly meetup for Python enthusiasts of all levels, traditionally gathering on the first Tuesday of the month. In-person meetings moved online during the COVID-19 pandemic, and the group's Meetup page has not listed a new event in a few years.
