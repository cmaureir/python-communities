<p><b>PyLadies</b> is an international mentorship group with a focus on helping more women become active participants and leaders in the Python open-source community. The group's mission is to promote, educate and advance a diverse Python community through outreach, education, conferences, events and social gatherings.</p>
<p><b>PyLadies</b> also aims to provide a friendly support network for women and a bridge to the larger Python world. Anyone with an interest in Python is encouraged to participate.</p>
<p><b>PyLadies Princeton</b> is one of the many local chapters of this international group, founded with the same mission to help women thrive in Python Open Source Community.</p>
<p>If you or someone you know would like to present or do a tech talk for PyLadies, please contact us.</p>
