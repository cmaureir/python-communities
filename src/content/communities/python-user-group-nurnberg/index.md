Hello Everyone!

This is the official Python User Group in Nürnberg, and its supported by the Python Software Foundation. This group is for anyone interested in learning Python and meeting people who share the same interest. It does not matter if you are a programming beginner or an experienced one, we are all learning and sharing our knowledge. All skill levels are welcome.

We maintain this group to share some of the amazing and powerful things that can be done using Python. Nowadays, Python is used almost everywhere, starting from creating fun projects for kids to analyzing complex and big data sets.
