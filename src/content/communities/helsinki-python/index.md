A local Python user group for the Greater Helsinki region meeting up roughly every month. See our webpage [here](https://helsinki-python.github.io/).

Please propose talks [here](https://forms.gle/KjZVgeMGHRd5ECCJ9) and follow the [code of conduct](https://helsinki-python.github.io/code-of-conduct).

Would you like to host a Helsinki Python meetup at your office? Please contact us: helsinki-python@googlegroups.com

See also [PyData Helsinki](https://pydata-helsinki.github.io/), [Archipylago](https://archipylago.dev/) in Turku, [PyLadies Tampere](https://www.linkedin.com/company/pyladies-tampere/), and [Techtribes](https://www.techtrib.es/) for more tech meetups in Finland.
