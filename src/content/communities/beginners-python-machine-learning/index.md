Beginners' Python and Machine Learning is a free, weekly support group in Sydney run by the SkyPy project to introduce complete beginners to Python programming. The first week of each month focuses on absolute beginners, with later sessions covering more advanced topics, and the group places special emphasis on increasing the number of women in STEM.
