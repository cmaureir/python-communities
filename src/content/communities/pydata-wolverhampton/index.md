PyData Wolverhampton is a community for anyone interested in data science, machine learning, and Python in the Black Country and wider West Midlands. Whether you're a student, hobbyist, or seasoned professional, join us to share ideas, learn from each other, and connect with the local data community. All skill levels welcome.

The PyData Code of Conduct governs this Meetup. To discuss any issues or concerns relating to the code of conduct or the behavior of anyone at a PyData meetup, please contact a co-organizer or NumFOCUS at admin@pydata.org.

PyData is an educational program of NumFOCUS, a 501(c)3 non-profit organization in the United States. PyData provides a forum for the international community of users and developers of data analysis tools to share ideas and learn from each other. The global PyData network promotes discussion of best practices, new approaches, and emerging technologies for data management, processing, analytics, and visualization. PyData communities approach data science using many languages, including (but not limited to) Python, Julia, and R.
