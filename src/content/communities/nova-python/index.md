[NOVA-PYTHON](https://nova-python.org/)

We talk about building applications using Python. Anything from startup prototypes to advanced data analysis with Numpy and Scipy. Python is a great choice due to the vast support community and ease of development.

Please find that we follow the Python Software Foundation's Code of Conduct found here: [https://policies.python.org/python.org/code-of-conduct/](https://policies.python.org/python.org/code-of-conduct/)

Any violations of the the Code of Conduct should be reported to the organizers promptly.

Our health and safety policy follows the [OSHA guidance](https://www.osha.gov/coronavirus/safework).
