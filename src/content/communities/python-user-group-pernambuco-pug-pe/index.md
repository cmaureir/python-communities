Python User Group Pernambuco (PUG-PE) is a community for Python enthusiasts across the Brazilian state of Pernambuco, historically centered in Recife. The group has held dozens of "Encontros" over the years covering open source tools, Django, and Python-based data science, though it has not organized new events in some time.
