Taipei.py 臺北 Python 使用者群組最早於 2012 年成立，提供 AI、機器學習、資料分析、財金、科學計算、Web 等各種基於 Python 生態系技術交流的場合，讓大台北的 Python 愛好者或對 Python 有興趣的人，能藉由難得的機會一起分享、研究、把玩、認識它五花八門的應用與技術，以及 Python 之美。

本群組由 PSF Python 軟體基金會支持重新開設，歡迎大家加入。

Welcome to Taipei.py!
Whether you're a beginner just starting out or a seasoned pro, we welcome all levels of expertise.
Our meetups will focus on a variety of topics related to Python, such as data analysis, web development, automation, and more. Join us to network with like-minded individuals, learn new skills, and collaborate on exciting projects. Let's explore the world of Python together in the vibrant tech community of Taipei!

Please check the [Code of Conduct](https://hackmd.io/@petertc/SJgnkKLn-e) for the friendly enviornment.
