**About**
Welcome to the home of the Spokane Python User Group (*SPUG*), Spokane's premiere local Python user group! We have a wide range of topics all related to Python, Web Development, and Open Source technology.

We typically meet around the **third Tuesday of each month** for presentations and workshops.

We also meet on the **first Monday of each month @ 7am** in Spokane for coffee and code.

All meetings are free, and we encourage everyone to participate and get involved and help grow the Python community. We try to base our meetings from attendee suggestions. If you have an idea for a topic that you would like to see or would like to present, fill out the on our website: **[https://spokanepython.com/](https://spokanepython.com/)**

**[Join our Discord server!](https://discord.gg/wHrSJNgpnP)**

**Code of Conduct**
Our Code of Conduct follows the Python Software Foundation's Code of Conduct, found here: [https://www.python.org/psf/conduct/](https://www.python.org/psf/conduct/).
