This group is for those who use the Python computer language or who want to learn more about it. Python is a great language for rapid development, with web frameworks that make getting a functional web application up and running quite easily.

Please also join the Central Ohio Python Users Group [mailing list](http://mail.python.org/mailman/listinfo/centraloh) and the Python channel on the [TechLife Columbus Slack](https://techlife-columbus-slack.herokuapp.com/).

We're always looking for topic suggestions and people interested in presenting at our monthly meetings.

In order to help maintain a vibrant Python community, we follow the Python Software Foundation's [code of conduct](https://policies.python.org/python.org/code-of-conduct/).
