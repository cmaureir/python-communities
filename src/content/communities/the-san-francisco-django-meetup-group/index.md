Django is a high-level Python Web framework that encourages rapid development and clean, pragmatic design. We meet every other month to discuss Django and related topics.

We follow [Django's Code of Conduct](https://www.djangoproject.com/conduct/) If you see anyone violating the rules defined there, please contact the organizer either at the meetup or via meetup.com!
Follow us on Twitter: https://twitter.com/sfdjangomeetup
